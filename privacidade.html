Política de Privacidade

Última atualização: 31 de outubro de 2026

Dados acessados

Com a autorização do usuário, o app Saldos usa o escopo drive.readonly do Google Drive apenas para localizar e ler o arquivo saldos.json, que o próprio usuário mantém no seu Drive.

Como os dados são usados

O conteúdo do arquivo é usado somente para exibir saldos, gráficos e relatórios na tela do aparelho do usuário.

Armazenamento

Uma cópia do último arquivo lido fica guardada apenas no armazenamento interno do app, no próprio aparelho, para permitir o uso sem internet. Ela é apagada ao desinstalar o app.

Compartilhamento

Nenhum dado é enviado a servidores do desenvolvedor ou de terceiros, vendido ou compartilhado. O app não usa publicidade nem ferramentas de análise.

O app consulta a API pública do Banco Central do Brasil apenas para obter a taxa do CDI. Nenhum dado do usuário é enviado nessa consulta.

Uso das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/connections.
